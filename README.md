# Airline_DataAnalysis_PowerBI
This project focuses on analyzing airline data using Microsoft Power BI. The dashboard provides interactive visualizations to understand airline performance, passenger traffic, seat capacity, fuel efficiency, and environmental impact.

#Dashboard Features

Passenger Analysis: Compare passenger numbers across different airlines.

Airline Performance: Analyze airline-wise passenger traffic.

Customer Satisfaction: Compare customer ratings across airlines.

Profitability Analysis: Visualize estimated profit by airline.

Fuel Efficiency: Analyze estimated fuel consumption efficiency.

Environmental Analysis: Monitor estimated CO₂ emissions per passenger.

Passenger Trends: Explore passenger trends over time.

Interactive Filters: Filter dashboard insights by airline.
